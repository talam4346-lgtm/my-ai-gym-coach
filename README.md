# ai-gym-coach
यह एक AI-आधारित जिम कोच प्रोजेक्ट है जो उपयोगकर्ताओं को सही पॉस्चर (posture) के साथ एक्सरसाइज करने में मदद करता है।

## विशेषताएं (Features)
* रीयल-टाइम पॉस्चर डिटेक्शन
* उपयोग में आसान यूजर इंटरफेस (UI)
* विभिन्न एक्सरसाइज सपोर्ट
